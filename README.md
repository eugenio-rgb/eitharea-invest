# EITHAREA Invest

Portal para inversionistas de EITHAREA, publicado en https://invest.eitharea.com

- El contenido se edita en el sitio de origen (Wix headless).
- La acción `Publicar invest.eitharea.com` copia el sitio, lo ajusta (dominio, mapa del sitio, página 404) y lo publica en GitHub Pages.
- Se ejecuta en cada cambio de este repositorio, todos los días a la 1:17 a. m. (hora de Monterrey) y manualmente desde la pestaña Actions.
